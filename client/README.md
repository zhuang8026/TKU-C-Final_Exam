# client — 前端畫面

## 檔案

| 檔案 | 負責內容 |
|------|---------|
| `index.html` | 頁面結構（停車格地圖 + 操作面板） |
| `style.css` | 樣式（grid 佈局、格位顏色、操作面板） |
| `app.js` | 邏輯（fetch 呼叫 Flask API、渲染地圖、顯示結果） |

## 功能

| 功能 | 說明 |
|------|------|
| 停車格地圖 | 3×3 grid，空位顯示綠色，佔用顯示紅色與車牌 |
| 入場 | 輸入車牌送出，即時更新地圖 |
| 出場 | 輸入車牌送出，被擋時顯示需先移出的車牌清單 |
| 歷史查詢 | 輸入車牌，顯示所有入出場時間紀錄 |

## 啟動方式

確認 Flask 已在 `http://127.0.0.1:5000` 運行，直接用瀏覽器開啟 `index.html`。
